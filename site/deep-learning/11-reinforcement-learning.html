Core ideas#

  • Setup: an agent observes state sss, takes action aaa, gets reward rrr and next state s′s's′. Goal: maximize the expected return Gt=∑kγkrt+kG_t = \sum_k \gamma^k r_{t+k}Gt​=∑k​γkrt+k​.
  • Value functions: Vπ(s)=Eπ[Gt∣s]V^\pi(s) = \mathbb E_\pi[G_t\mid s]Vπ(s)=Eπ​[Gt​∣s], Qπ(s,a)=Eπ[Gt∣s,a]Q^\pi(s,a) = \mathbb E_\pi[G_t\mid s,a]Qπ(s,a)=Eπ​[Gt​∣s,a]. Advantage A=Q−VA = Q - VA=Q−V.
  • Bellman equation: Q∗(s,a)=E[r+γmax⁡a′Q∗(s′,a′)]Q^*(s,a) = \mathbb E[r + \gamma\max_{a'}Q^*(s',a')]Q∗(s,a)=E[r+γmaxa′​Q∗(s′,a′)]. A recursive consistency condition. 🔭 Analogous to the principle of optimality / Hamilton–Jacobi–Bellman.
  • Dynamic programming (known model): value iteration, policy iteration.
  • Model-free, value-based:
    • TD learning: bootstrap from your own estimate, V(s)←V(s)+α[r+γV(s′)−V(s)]V(s) \leftarrow V(s) + \alpha[r + \gamma V(s') - V(s)]V(s)←V(s)+α[r+γV(s′)−V(s)].
    • Q-learning: off-policy TD on QQQ. DQN (Atari, 2013/15) = Q-learning + a neural net + replay buffer + target network.
  • Policy-based:
    • REINFORCE / policy gradient: increase the log-probability of actions with high advantage. Unbiased but high-variance → subtract a baseline V(s)V(s)V(s).
    • Actor-critic: the actor = policy, the critic = value estimate. GAE for advantage estimation.
    • PPO: clip the policy ratio rt=πθ/πoldr_t = \pi_\theta/\pi_{old}rt​=πθ​/πold​ to [1−ϵ,1+ϵ][1-\epsilon, 1+\epsilon][1−ϵ,1+ϵ] for stable updates. The workhorse algorithm.
    • SAC: max-entropy RL for continuous control. 🔭 Free-energy / temperature again.
  • Model-based RL: learn a world model and plan with it (MuZero, Dreamer). AlphaGo/AlphaZero = MCTS + policy/value nets + self-play.
  • RL ↔ LLMs:
    • RLHF: reward = a learned human-preference model. PPO + KL penalty to stay close to the SFT model.
    • RL with verifiable rewards: reward = a correct math answer or passing unit tests. GRPO drops the critic and uses group-relative advantages over several sampled answers. This is what produces "reasoning" models.
    • Risk: reward hacking. The policy exploits flaws in the reward.
  • Why RL is hard: sparse/delayed rewards, credit assignment, non-stationary data, high variance, and extreme sensitivity to hyperparameters and seeds.

Learn from#

  • ⭐ Sutton & Barto: Reinforcement Learning, an Introduction (2nd ed.): free. Ch. 1–6, 9, 13. The foundational text.
  • ⭐ OpenAI Spinning Up in Deep RL: the bridge to deep RL. Read "Introduction to RL" parts 1–3, then the algorithm docs.
  • David Silver's RL course (UCL/DeepMind): classic lectures that pair with Sutton & Barto.
  • Hugging Face Deep RL Course: hands-on and free.
  • CleanRL: single-file, readable implementations to study. Gymnasium for environments.
  • The 37 Implementation Details of PPO: why your PPO doesn't work.
  • Advanced: UC Berkeley CS285 (Sergey Levine).

Build#

  1. Tabular Q-learning on FrozenLake / CliffWalking. Visualize the value function.
  2. DQN on CartPole (then Atari Pong if you have a GPU).
  3. REINFORCE → actor-critic → PPO on CartPole/LunarLander, each written by you and compared against CleanRL.
  4. Stretch: a GRPO-style RL fine-tune of a tiny LM on arithmetic problems with a verifiable reward (trl has a GRPOTrainer).
  5. 🔭 Fun: train an agent on a physics environment (MuJoCo via Gymnasium: Hopper, Ant).
