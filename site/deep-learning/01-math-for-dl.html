01 · Math for Deep Learning

🧠 Deep Learning · Module 01
goal the math DL actually uses and nothing more.time 15–25 hneeds high-school calculus

You're strong at math, so this module skips the basics. It covers three things school usually doesn't: linear algebra as geometry, matrix calculus, and probability/information theory for ML.

Skip test#

Core ideas#

Linear algebra (geometry first)#

  • Vectors are data points. Matrices are linear maps, and ABABAB means "apply BBB, then AAA".
  • Dot product a⋅b=∥a∥∥b∥cos⁡θ\mathbf a\cdot\mathbf b = \|\mathbf a\|\|\mathbf b\|\cos\thetaa⋅b=∥a∥∥b∥cosθ measures similarity. It's the core of attention.
  • Rank = dimension of the output space. Low-rank ideas drive LoRA and compression.
  • Eigen-decomposition A=QΛQ⊤A = Q\Lambda Q^\topA=QΛQ⊤ (symmetric AAA): the axes the map only stretches.
  • SVD A=UΣV⊤A = U\Sigma V^\topA=UΣV⊤ (any AAA): rotate → scale → rotate. This underlies PCA, low-rank approximation, and conditioning.
  • Norms: ∥⋅∥2\|\cdot\|_2∥⋅∥2​ (weight decay), ∥⋅∥1\|\cdot\|_1∥⋅∥1​ (sparsity), Frobenius norm for matrices.
  • Shapes are everything. In DL, data is a batch matrix X∈RN×dX \in \mathbb{R}^{N\times d}X∈RN×d (rows = examples).

Calculus → matrix calculus#

  • Gradient ∇f\nabla f∇f points uphill. It is the steepest-ascent direction, perpendicular to level sets.
  • Jacobian Jij=∂yi/∂xjJ_{ij} = \partial y_i / \partial x_jJij​=∂yi​/∂xj​. Chain rule: Jf∘g=Jf JgJ_{f\circ g} = J_f \, J_gJf∘g​=Jf​Jg​. Backprop = the chain rule applied right-to-left (vector-Jacobian products).
  • Identities worth memorizing:
    • ∇x(a⊤x)=a\nabla_{\mathbf x}(\mathbf a^\top\mathbf x) = \mathbf a∇x​(a⊤x)=a
    • ∇x(x⊤Ax)=(A+A⊤)x\nabla_{\mathbf x}(\mathbf x^\top A\mathbf x) = (A+A^\top)\mathbf x∇x​(x⊤Ax)=(A+A⊤)x
    • ∇w∥Xw−y∥2=2X⊤(Xw−y)\nabla_{\mathbf w}\|X\mathbf w-\mathbf y\|^2 = 2X^\top(X\mathbf w-\mathbf y)∇w​∥Xw−y∥2=2X⊤(Xw−y)
  • Shape trick: the gradient of a scalar w.r.t. a matrix has the same shape as that matrix. Use this to check every derivation.
  • Hessian H=∇2fH = \nabla^2 fH=∇2f gives curvature. Convex means H⪰0H \succeq 0H⪰0. The condition number λmax⁡/λmin⁡\lambda_{\max}/\lambda_{\min}λmax​/λmin​ sets how hard optimization is.
  • Taylor: f(x+δ)≈f+∇f⊤δ+12δ⊤Hδf(\mathbf x+\boldsymbol\delta) \approx f + \nabla f^\top\boldsymbol\delta + \tfrac12\boldsymbol\delta^\top H\boldsymbol\deltaf(x+δ)≈f+∇f⊤δ+21​δ⊤Hδ. This is where every optimizer comes from.

Optimization#

  • Gradient descent: θ←θ−η∇L\theta \leftarrow \theta - \eta\nabla Lθ←θ−η∇L. On a quadratic it's stable only if η<2/λmax⁡\eta < 2/\lambda_{\max}η<2/λmax​.
  • 🔭 Physics: GD is an overdamped particle in potential LLL. Momentum is a heavy ball with friction. SGD noise acts like temperature.
  • Stochastic GD: gradients estimated on mini-batches. Noisy but cheap, and the noise even helps generalization.
  • Lagrange multipliers show up in constrained derivations (e.g. max-entropy → softmax, SVMs).

Probability & statistics#

  • Random variables, expectation, variance. Linearity: E[aX+bY]=aEX+bEY\mathbb E[aX+bY]=a\mathbb E X+b\mathbb E YE[aX+bY]=aEX+bEY.
  • Bayes: p(θ∣D)∝p(D∣θ) p(θ)p(\theta\mid D) \propto p(D\mid\theta)\,p(\theta)p(θ∣D)∝p(D∣θ)p(θ), i.e. posterior ∝ likelihood × prior.
  • Key distributions: Bernoulli/Categorical (classification), Gaussian (regression, noise, VAEs, diffusion).
  • Maximum likelihood (MLE): θ∗=arg⁡max⁡∑ilog⁡p(xi∣θ)\theta^* = \arg\max \sum_i \log p(x_i\mid\theta)θ∗=argmax∑i​logp(xi​∣θ). Almost every DL loss is a negative log-likelihood:
    • Gaussian likelihood → MSE. Bernoulli/Categorical → cross-entropy.
  • MAP = MLE + prior. A Gaussian prior is exactly L2 weight decay.
  • Monte Carlo: Ep[f]≈1N∑f(xi)\mathbb E_p[f] \approx \frac1N\sum f(x_i)Ep​[f]≈N1​∑f(xi​). Also the reparameterization trick x=μ+σϵx=\mu+\sigma\epsilonx=μ+σϵ (VAEs, diffusion).

Information theory#

  • Entropy H(p)=−∑plog⁡pH(p) = -\sum p\log pH(p)=−∑plogp: average surprise. 🔭 Same form as Gibbs entropy.
  • Cross-entropy H(p,q)=−∑plog⁡qH(p,q) = -\sum p\log qH(p,q)=−∑plogq: the classification loss.
  • KL divergence DKL(p∥q)=∑plog⁡pq=H(p,q)−H(p)≥0D_{KL}(p\|q)=\sum p\log\frac{p}{q} = H(p,q)-H(p) \ge 0DKL​(p∥q)=∑plogqp​=H(p,q)−H(p)≥0 (Jensen). It's asymmetric.
  • Softmax σ(z)i=ezi/∑jezj\sigma(\mathbf z)_i = e^{z_i}/\sum_j e^{z_j}σ(z)i​=ezi​/∑j​ezj​. 🔭 This is the Boltzmann distribution with energy −zi-z_i−zi​ and temperature 1. The "temperature" in LLM sampling is literally TTT.

Learn from#

  • ⭐ Mathematics for Machine Learning, Deisenroth, Faisal & Ong (free PDF). Read ch. 2–7 selectively. Skim what you know.
  • ⭐ The Matrix Calculus You Need for Deep Learning, Parr & Howard. A short article that's essential.
  • 3Blue1Brown: Essence of Linear Algebra: watch it once for geometric intuition (~3 h).
  • Optional depth: MIT 18.06 (Strang), Harvard Stat 110 (Blitzstein), MIT 18.S096 Matrix Calculus for ML.

Build#

  1. Derive ∇w\nabla_{\mathbf w}∇w​ for linear regression by hand. Then check it numerically with finite differences f(w+h)−f(w−h)2h\frac{f(w+h)-f(w-h)}{2h}2hf(w+h)−f(w−h)​ in NumPy.
  2. Write PCA with np.linalg.svd on a toy 2D dataset and plot the principal axes.
  3. Simulate GD on f(x,y)=x2+10y2f(x,y)=x^2+10y^2f(x,y)=x2+10y2 with different η\etaη. Watch the oscillation and divergence, and relate it to the condition number.

Traps#

  • Memorizing formulas without checking shapes → derive with shapes, then verify numerically.
  • Over-studying math up front. Learn the rest just in time when a later module needs it.
