Core ideas#

  • Attention: Attention(Q,K,V)=softmax ⁣(QK⊤dk+M)V\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)VAttention(Q,K,V)=softmax(dk​​QK⊤​+M)V
    • Q=XWQ, K=XWK, V=XWVQ = XW_Q,\ K = XW_K,\ V = XW_VQ=XWQ​, K=XWK​, V=XWV​. Each token queries every other token's keys and takes a weighted mix of their values.
    • Why dk\sqrt{d_k}dk​​: for random unit-variance entries, q⋅k\mathbf q\cdot\mathbf kq⋅k has variance dkd_kdk​. Dividing keeps the softmax out of its saturated (zero-gradient) regime.
    • Mask MMM: −∞-\infty−∞ above the diagonal = causal (can't see the future). This lets one forward pass train on all TTT next-token predictions at once.
    • Attention is a set operation: permutation-equivariant, with no built-in notion of order.
  • Multi-head: split dmodeld_{model}dmodel​ into hhh heads of size dk=dmodel/hd_k = d_{model}/hdk​=dmodel​/h. Each head learns a different relation (syntax, coreference, position…). Concatenate, then project with WOW_OWO​.
  • Transformer block (modern pre-norm, GPT-style):
    x = x + Attention(LayerNorm(x))
x = x + MLP(LayerNorm(x))        # MLP: d → 4d → d, GELU (or SwiGLU in Llama-style models)
    Residual stream view: every layer reads from and writes to a shared residual stream. This is the basis of interpretability work.
  • Positional encoding:
    • Sinusoidal (original), learned absolute (GPT-2), RoPE (rotates Q/K by a position-dependent angle so attention depends on relative position; used by Llama, Qwen, and most modern LLMs).
    • 🔭 RoPE is a complex-phase rotation eimθe^{i m\theta}eimθ: relative phase = relative position.
  • Complexity: O(T2d)O(T^2 d)O(T2d) compute and O(T2)O(T^2)O(T2) memory for the score matrix. Fixes: FlashAttention (exact, tiles in fast GPU SRAM, never stores T×TT\times TT×T), sparse/sliding-window attention, linear attention, and state-space models (module 12).
  • Three families:
    • Encoder-only (BERT): bidirectional, masked-token objective → classification and embeddings.
    • Decoder-only (GPT): causal, next-token objective → generation. Dominant today.
    • Encoder-decoder (T5, original Transformer): translation and seq2seq.
  • Parameter count (decoder): ≈ 12 L d212\,L\,d^212Ld2 (attention 4d24d^24d2 + MLP 8d28d^28d2 per layer), plus embeddings VdV dVd.
  • Same block everywhere: text, images (ViT), audio (Whisper), proteins (AlphaFold-style components), actions (robotics). Learn it once and it applies everywhere.

Learn from#

  • ⭐ Let's build GPT: from scratch, in code, spelled out (Karpathy) + nanoGPT / build-nanogpt (the "Let's reproduce GPT-2 (124M)" video).
  • ⭐ The Illustrated Transformer (Jay Alammar): read before the video.
  • Attention Is All You Need (2017): read the paper after building it. It'll be easy by then.
  • The Annotated Transformer (Harvard NLP): the paper line by line in PyTorch.
  • 3Blue1Brown: Transformers & Attention (chapters 5–7): superb visual intuition.
  • Transformer Explainer (interactive): GPT-2 running live in the browser.
  • Understanding Deep Learning (Prince) ch. 12.

Build#

  1. Single-head attention in NumPy, checked against torch.nn.functional.scaled_dot_product_attention.
  2. nanoGPT from a blank file on Tiny Shakespeare (char-level). Then add: multi-head, pre-norm, dropout, weight tying, LR warmup + cosine, AdamW.
  3. Swap learned positions for RoPE and compare validation loss. Try a longer context.
  4. Stretch: reproduce GPT-2 124M on FineWeb-Edu following build-nanogpt (needs a rented GPU: roughly 1–2 h on 8×A100, or a day-plus on a single GPU).

Traps#

  • Mixing up (B, T, C) and (B, heads, T, head_dim) reshapes/transposes. Write the shapes in comments.
  • A causal mask applied after the softmax (wrong) instead of before (right).
  • Thinking you understand it after watching. Close the video and rebuild from nothing.
