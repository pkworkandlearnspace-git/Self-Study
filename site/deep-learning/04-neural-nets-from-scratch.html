04 · Neural Networks from Scratch

🧠 Deep Learning · Module 04
goal understand backprop so well you could build PyTorch's core yourself.time 15–20 hneeds 01, 03

The most important module. Everything after this is architecture choices on top of the same engine.

Skip test#

Core ideas#

  • Neuron: a=ϕ(w⊤x+b)a = \phi(\mathbf w^\top\mathbf x + b)a=ϕ(w⊤x+b). Layer: h=ϕ(Wx+b)\mathbf h = \phi(W\mathbf x + \mathbf b)h=ϕ(Wx+b). MLP: a stack of layers.
  • Why nonlinearity: W2(W1x)=(W2W1)xW_2(W_1\mathbf x) = (W_2W_1)\mathbf xW2​(W1​x)=(W2​W1​)x is still linear. ϕ\phiϕ (ReLU, GELU, tanh) gives expressive power.
  • Universal approximation: one wide hidden layer can approximate any continuous function. Depth makes it efficient (exponentially fewer units for compositional functions).
  • Computational graph: each op is a node. Forward computes values. Backward sends gradients from the loss back to every parameter.
  • Backprop = chain rule + caching. Each node only needs its local derivative and the upstream gradient: grad_input = local_jacobianᵀ · grad_output
  • Key local gradients (for y=Wx\mathbf y = W\mathbf xy=Wx in batch form Y=XW⊤Y = XW^\topY=XW⊤):
    • ∂L/∂W=(∂L/∂Y)⊤X\partial L/\partial W = (\partial L/\partial Y)^\top X∂L/∂W=(∂L/∂Y)⊤X, ∂L/∂X=(∂L/∂Y) W\partial L/\partial X = (\partial L/\partial Y)\, W∂L/∂X=(∂L/∂Y)W
    • ReLU: pass the gradient where input > 0, zero elsewhere.
    • Softmax + CE combined: y^−y\hat{\mathbf y} - \mathbf yy^​−y (clean and stable, which is why frameworks fuse them).
  • Gradients accumulate (+=) when a value is used in several places. This is the multivariable chain rule.
  • Reverse-mode AD costs ~2–3× a forward pass, whatever the number of parameters. That's why training billion-parameter nets is possible.
  • Activations: sigmoid/tanh saturate → vanishing gradients. ReLU doesn't saturate for x > 0 (but neurons can "die"). GELU/SiLU are smooth variants used in transformers.
  • Initialization matters: variance-preserving init keeps signals from exploding or vanishing — Xavier/Glorot Var(w)=1/nin\text{Var}(w)=1/n_{in}Var(w)=1/nin​ (tanh), He/Kaiming 2/nin2/n_{in}2/nin​ (ReLU).

Learn from#

  • ⭐ Neural Networks: Zero to Hero (Andrej Karpathy): videos 1–5 (micrograd → makemore with MLPs, BatchNorm, "Becoming a Backprop Ninja"). Code along with every line. This is the best single resource in the whole curriculum.
  • 3Blue1Brown: Neural Networks: the intuition, watched first (~1.5 h).
  • Neural Networks and Deep Learning (Michael Nielsen): free book. Ch. 1–3 for a clear backprop derivation.
  • CS231n: Backprop notes + Yes you should understand backprop.

Build#

  1. micrograd: a scalar autograd engine (~150 lines) plus a tiny MLP that learns a 2D dataset (moons). Follow Karpathy, then rewrite it from memory.
  2. NumPy MLP on MNIST with hand-derived matrix backprop. Target ≥ 97% test accuracy. Gradient-check every layer.
  3. 💡 C++ bonus: port micrograd to C++ (a Value class with shared_ptr children and a topological sort). It cements the graph idea and uses your STL skills.

Traps#

  • "I understand it from the video." You don't until you've written it from a blank file.
  • Forgetting to zero gradients between steps (they accumulate).
  • Using float32 for gradient checks. Use float64.
