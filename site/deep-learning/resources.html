Resources: the curated master list

Rule: ⭐ = the main resource, and the only one you need. Everything else is optional depth or an alternative explanation if the ⭐ doesn't click. All ⭐ items are free unless marked 💲.

The core stack (if you only use five things)#

  1. ⭐ Karpathy: Neural Networks Zero to Hero: build everything from scratch (modules 04, 07, 08, 09)
  2. ⭐ Understanding Deep Learning (Prince, 2023): the theory textbook (all modules)
  3. ⭐ Dive into Deep Learning (d2l.ai): the textbook with runnable PyTorch code (05–07)
  4. ⭐ Stanford CS231n → CS336: university-grade assignments (06, 09)
  5. ⭐ Mathematics for Machine Learning: math, only when you need it (01)

Books (free online unless 💲)#

Book Best for
Understanding Deep Learning, Prince modern, clear, illustrated. Best overall DL textbook

Deep Learning: Foundations and Concepts, Bishop & Bishop rigorous, probabilistic view (free online viewing)
Deep Learning, Goodfellow, Bengio, Courville classic (2016). Part I math and Part II are still great
Probabilistic Machine Learning, Murphy encyclopedic reference (Book 1 + 2)
Neural Networks and Deep Learning, Nielsen gentlest backprop introduction
An Introduction to Statistical Learning (ISLP) classical ML with Python
Reinforcement Learning, Sutton & Barto RL foundations
The Principles of Deep Learning Theory physics-style DL theory (advanced)
Geometric Deep Learning, Bronstein et al. symmetry, GNNs, equivariance
How to Scale Your Model (DeepMind) LLM systems and parallelism
💲 Build a Large Language Model (From Scratch), Raschka LLMs step by step (free code)
💲 Programming Massively Parallel Processors, Hwu et al. CUDA / GPU programming

Paper reading order#

Read each one after the module that covers it, when it'll feel easy. ✅ = reimplement a small version.

Foundations

  1. Learning representations by back-propagating errors (Rumelhart et al., 1986): backprop (just skim)
  2. ImageNet Classification with Deep CNNs, AlexNet (2012)
  3. Adam (2014) · Decoupled Weight Decay, AdamW (2017)
  4. Dropout (2014) · Batch Normalization (2015) · Layer Normalization (2016)
  5. ✅ Deep Residual Learning, ResNet (2015)

Sequences → Transformers 6. word2vec (2013) · Seq2Seq (2014) · Bahdanau Attention (2014) 7. ✅ Attention Is All You Need (2017) 8. BERT (2018) · ✅ GPT-2 (2019) · GPT-3 (2020) 9. ViT (2020) · RoFormer / RoPE (2021) · FlashAttention (2022)

LLMs 10. Scaling Laws (Kaplan, 2020) · Chinchilla (2022) 11. InstructGPT / RLHF (2022) · ✅ LoRA (2021) · DPO (2023) 12. Llama (2023) · Chain-of-Thought (2022) · RAG (2020) 13. Mixtral / MoE (2024) · DeepSeek-R1 (2025) (RL for reasoning, GRPO)

Generative 14. ✅ VAE (2013) · GAN (2014) 15. ✅ DDPM (2020) · Score-based SDEs (2020) · Classifier-Free Guidance (2022) 16. Latent Diffusion (2021) · DiT (2022) · ✅ Flow Matching (2022) 17. CLIP (2021)

RL 18. ✅ DQN, Atari (2013) · AlphaGo Zero (2017) · ✅ PPO (2017)

Frontier/theory (pick by track) 19. Double Descent (2019) · NTK (2018) · Grokking (2022) 20. A Mathematical Framework for Transformer Circuits (2021) · Toy Models of Superposition (2022) 21. Mamba (2023) · PINNs (2017) · Fourier Neural Operator (2020)
