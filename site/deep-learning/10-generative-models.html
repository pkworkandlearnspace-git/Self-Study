10 · Generative Models

🧠 Deep Learning · Module 10
goal learn the four big ideas for modeling p(x): autoregressive, VAE, GAN, diffusion/flow.time 25–35 hneeds 01, 05

🔭 This module is where physics pays off most: diffusion is Langevin dynamics, score matching is about gradients of log-densities, flow matching moves probability mass by ODEs (continuity equation), and energy-based models are Boltzmann distributions.

Autoencoders & VAEs#

  • Autoencoder: encoder → bottleneck zzz → decoder, trained to reconstruct. It compresses, but it isn't a generative model.
  • VAE: encoder outputs qϕ(z∣x)=N(μ,σ2)q_\phi(z\mid x) = \mathcal N(\mu,\sigma^2)qϕ​(z∣x)=N(μ,σ2), prior p(z)=N(0,I)p(z)=\mathcal N(0,I)p(z)=N(0,I).
    • Loss = −ELBO = reconstruction + KL. Reparameterize z=μ+σ⊙ϵ, ϵ∼N(0,I)z = \mu + \sigma\odot\epsilon,\ \epsilon\sim\mathcal N(0,I)z=μ+σ⊙ϵ, ϵ∼N(0,I) so gradients flow through the sampling step.
    • 🔭 The ELBO is the (negative) variational free energy from statistical mechanics.

GANs#

  • min⁡Gmax⁡D E[log⁡D(x)]+E[log⁡(1−D(G(z)))]\min_G\max_D\ \mathbb E[\log D(x)] + \mathbb E[\log(1 - D(G(z)))]minG​maxD​ E[logD(x)]+E[log(1−D(G(z)))], a two-player game.
  • Problems: unstable training, mode collapse. Fixes: WGAN (Wasserstein distance), spectral norm, StyleGAN tricks. Mostly displaced by diffusion, but the ideas live on (adversarial losses in VAE decoders, distillation).

Diffusion models (DDPM)#

  • Forward: gradually add Gaussian noise, q(xt∣x0)=N(αˉt x0, (1−αˉt)I)q(x_t\mid x_0) = \mathcal N(\sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I)q(xt​∣x0​)=N(αˉt​​x0​, (1−αˉt​)I). So xt=αˉt x0+1−αˉt ϵx_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilonxt​=αˉt​​x0​+1−αˉt​​ϵ.
  • Train: a network ϵθ(xt,t)\epsilon_\theta(x_t, t)ϵθ​(xt​,t) predicts the noise. Loss ∥ϵ−ϵθ(xt,t)∥2\|\epsilon - \epsilon_\theta(x_t,t)\|^2∥ϵ−ϵθ​(xt​,t)∥2. Literally an MSE regression.
  • Sample: start from pure noise and denoise step by step.
  • Score view: ϵθ∝−∇xlog⁡pt(x)\epsilon_\theta \propto -\nabla_x \log p_t(x)ϵθ​∝−∇x​logpt​(x) (the score). Sampling = Langevin dynamics / a reverse-time SDE (Song et al.). 🔭 Fokker–Planck, Brownian motion.
  • Speedups: DDIM (deterministic ODE sampling, fewer steps), consistency models, distillation.
  • Conditioning: text via cross-attention (CLIP/T5 embeddings). Classifier-free guidance: ϵ^=ϵuncond+w(ϵcond−ϵuncond)\hat\epsilon = \epsilon_{uncond} + w(\epsilon_{cond} - \epsilon_{uncond})ϵ^=ϵuncond​+w(ϵcond​−ϵuncond​).
  • Latent diffusion (Stable Diffusion): diffuse in a VAE's latent space → much cheaper. Backbone: U-Net → Diffusion Transformer (DiT) in modern models.

Flow matching / rectified flow (current state of the art)#

  • Learn a velocity field vθ(x,t)v_\theta(x,t)vθ​(x,t) whose ODE x˙=vθ\dot x = v_\thetax˙=vθ​ carries noise to data along (nearly) straight paths. With x0x_0x0​ = noise and x1x_1x1​ = data, interpolate linearly xt=(1−t)x0+tx1x_t = (1-t)x_0 + t x_1xt​=(1−t)x0​+tx1​ and regress vθ(xt,t)v_\theta(x_t,t)vθ​(xt​,t) onto x1−x0x_1 - x_0x1​−x0​. That's again a plain MSE.
  • 🔭 A continuity equation ∂tp+∇⋅(pv)=0\partial_t p + \nabla\cdot(p v) = 0∂t​p+∇⋅(pv)=0 is transporting probability mass. Used in Stable Diffusion 3, Flux, and many video models.

Also know#

  • Normalizing flows: invertible maps with exact likelihood via the change of variables log⁡p(x)=log⁡p(z)+log⁡∣det⁡∂z/∂x∣\log p(x) = \log p(z) + \log|\det \partial z/\partial x|logp(x)=logp(z)+log∣det∂z/∂x∣.
  • Energy-based models: p(x)∝e−E(x)p(x) \propto e^{-E(x)}p(x)∝e−E(x) (🔭 Boltzmann). Hard to normalize, sampled with MCMC.

  • Papers: VAE · GAN · DDPM · Score SDE · Latent Diffusion · CFG · DiT · Flow Matching.

Build#

  1. VAE on MNIST: visualize the 2D latent space and interpolate between digits.
  2. DCGAN on a small image dataset. Observe instabilities and mode collapse.
  3. DDPM from scratch (small U-Net) on MNIST/Fashion-MNIST, then add class conditioning + classifier-free guidance.
  4. Flow matching on 2D toy data (e.g. moons → spiral), then on MNIST. Compare sampling steps with DDPM.
  5. Stretch: fine-tune Stable Diffusion with LoRA/DreamBooth on your own images using diffusers.
