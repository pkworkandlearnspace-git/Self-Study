Informatics Olympiad Resources

⭐ = the main resource · 💲 = paid · everything else is free.

The core stack#

  1. ⭐ USACO Guide: a structured curriculum from Bronze to Platinum, with problems per topic. Use it as the spine of modules 01–07.
  2. ⭐ CSES Problem Set (300+ classic problems) + Competitive Programmer's Handbook (free PDF, Laaksonen).
  3. ⭐ AtCoder Educational DP Contest: for module 05.
  4. ⭐ Past IOI and olympiad tasks on oj.uz: subtask-judged practice.

References#

  • cp-algorithms: an encyclopedia of algorithms with proofs and code.
  • KACTL: a well-tested code library (great for learning clean implementations).
  • Guide to Competitive Programming, Laaksonen 💲 (the expanded handbook) · Algorithms, Erickson (free) for proofs.
  • cppreference.

Practice & contests#

  • Codeforces: weekly contests, plus the EDU section (segment tree, DSU, binary search courses).
  • AtCoder: ABC (beginner–intermediate), ARC/AGC (hard, math-flavored).
  • IOI official site: the syllabus and past tasks.
  • Past APIO, BOI, CEOI, JOI, EGOI, and your national olympiad problems (most are on oj.uz).

Video#

  • Errichto (YouTube): problem solving, DP, binary search.
  • Colin Galen, William Lin (YouTube): contest walkthroughs and how they practice.

This repo#

  • Interactive tools: graph search, segment tree, DP table, flashcards.
