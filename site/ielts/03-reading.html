03 · Reading (Academic)

🗣️ IELTS Academic · Module 03
goal ≥ 30/40 (band 7), 33+ for 7.5.time 2 weeks, then maintenance

Format#

3 long passages (journals, books, magazines; ~2,150–2,750 words total), 40 questions, 60 minutes, with no extra transfer time. Aim for ~17 / 20 / 23 min per passage, since passage 3 is the hardest.

Question types & tactics#

Type Tactic
True / False / Not Given (facts) · Yes / No / Not Given (writer's views) False = the text contradicts it. Not Given = the text says nothing about it. Don't use outside knowledge. Watch qualifiers: all/some/always/usually.
Matching headings Read the headings first. Skim each paragraph's first and last sentences for its main idea, not a detail. Do it before the detail questions.
Matching information (which paragraph contains…) Usually not in order and hardest. Do it last, after you know the text.
Sentence / summary / note completion Respect the word limit. Answers usually come in text order. Check the grammar of the gap.
Multiple choice Find the relevant part, then eliminate. The correct option is usually a paraphrase, while the wrong ones reuse text words.
Diagram labeling / short answer Scan for keywords and numbers.

Core techniques#

  • Skim (2–3 min): get the topic and paragraph structure. Scan: hunt for names, numbers, and keywords.
  • Paraphrase awareness again: "decline" ↔ "fall", "a growing number of" ↔ "increasingly".
  • Time discipline: never spend > 2 min on one question. Mark it and return.
  • Read widely daily (academic register): The Economist, Scientific American, New Scientist, The Conversation. Your physics/math reading counts if it's in English!

Practice routine#

  • Do one passage a day under time pressure. For each error, find the exact sentence in the text that gives the answer, and write why you chose wrong.
