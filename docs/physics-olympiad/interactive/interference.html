Wave Interference & Diffraction

Part 1: two coherent point sources make ripples, and you can see the nodal lines form. Part 2: the far-field intensity of an N-slit grating with finite slit width (module 05).

1 · Two-source ripple tank

Nodal (dark) lines satisfy |r₁ − r₂| = (m + ½)λ for in-phase sources. They are hyperbolas with the sources as foci. The number of lines ≈ 2d/λ.

2 · N-slit grating on a far screen

I(θ) totalsingle-slit envelope (sin β / β)²
I(θ) = I₀ · (sin β / β)² · (sin Nα / (N sin α))², with α = π d sinθ / λ and β = π a sinθ / λ. Principal maxima: d sinθ = mλ. There are N − 2 small secondary maxima between them. A maximum goes missing when it lands on a single-slit zero (d/a an integer).
