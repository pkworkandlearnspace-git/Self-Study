Modular Arithmetic Lab

See orders, primitive roots, and Fermat/Euler at work. The order of a mod n is the smallest d with ad ≡ 1. It's the single most useful idea in olympiad number theory (module 03).

cycle 1 → a → a² → … → 1 not coprime to n

Power table ak mod n

Rows: bases coprime to n. Blue cells: ak ≡ 1. A green row label = primitive root (order = φ(n)). Click a row to select that base.

Try these

  1. For prime n, does every order divide n − 1? (Fermat + order lemma.)
  2. For n = 13, count the elements of each order d. Compare with φ(d).
  3. Find an n with no primitive root (try 8, 12, 15). Primitive roots exist only for n = 1, 2, 4, pk, 2pk.
  4. For prime p, is (p−1)! ≡ −1? Check Wilson's theorem in the panel.
