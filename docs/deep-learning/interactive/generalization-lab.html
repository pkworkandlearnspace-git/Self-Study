Generalization Lab

Two experiments every model inherits. Part 1: fit polynomials and watch under- and overfitting appear in the train/validation gap. Part 2: move a decision threshold and see why accuracy lies on imbalanced data.

Try this

  1. Degree 0 and 1: both errors high and close together → underfitting (high bias).
  2. Degree 12–15 with N = 15: train error near 0, validation error explodes → overfitting (high variance). Tick "Show 25 fits" to see the variance directly.
  3. Keep degree 15 and raise N to 200. More data tames a big model.
  4. Keep degree 15, N = 15, and raise λ. Regularization shrinks the wiggles. Too much λ underfits again.
  5. Set noise σ = 0. Now even degree 15 generalizes well: overfitting is fitting the noise.

Try this

  1. Prevalence 1%: push the threshold far right. Accuracy hits ~99% while recall is ~0, the same as "always predict 0".
  2. Change prevalence only. The ROC curve and AUC don't move (they condition on the true class), but precision and the PR curve change a lot. On rare positives, look at precision/recall.
  3. Set d′ = 0 (a useless model): the ROC is the diagonal and AUC = 0.5.
  4. Find the threshold that maximizes F1. Is it the same as the one that maximizes accuracy?
