Broadcasting Lab

Silent shape bugs are the most common bug in DL code. Type two shapes and see NumPy's rule in action: align from the right; each pair of dims must be equal or one of them 1; size-1 dims stretch; missing dims count as 1. PyTorch uses the same rule. Then drill it in the quiz.

Solid cells are real data. Faded cells are virtual copies made by stretching a size-1 axis: no memory is copied.
