Attention & Sampling

The two softmaxes at the heart of every LLM: attention weights = softmax(q·k / √d), and next-token sampling = softmax(logits / T). Drag the vectors and move the sliders (modules 08–09).

1 · Scaled dot-product attention (2D toy)

Drag the query q and the keys k₁…k₄. Each key carries a value (a word). The output is the attention-weighted mix of values.

2 · Causal mask

Row i = the query at position i. Entries above the diagonal are set to −∞ before the softmax, so token i can only attend to tokens ≤ i. That lets one forward pass train all T next-token predictions in parallel. The numbers are random toy weights, but every row sums to 1.

3 · Next-token sampling: temperature, top-k, top-p

Context: "The capital of France is …". Drag the logit sliders on the left to change the model's raw scores.
