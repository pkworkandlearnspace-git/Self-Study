Functional Equations Trainer

Guess a solution, test it against the equation at random points, then reveal the substitutions one at a time. A guess that passes is only a candidate: the proof must show there are no others. Module 02.

Hints (substitutions in order)

    Press Next hint to reveal the first step.

    Syntax: x, numbers, + − * / ^, brackets, and sqrt abs exp log sin cos floor pi. You may omit * after a number: 2x+1.

    The standard toolkit

    1. Plug in special values: x = 0, y = 0, x = y, y = −x, y = 1. Find f(0), f(1), and the parity of f.
    2. Swap the variables and compare, when the equation is not symmetric.
    3. Injectivity / surjectivity: if f(a) = f(b) forces a = b, you can cancel f. If one side ranges over all reals as y varies, f is onto.
    4. Linear systems: replace x by 1 − x, 1/x, … to get a second equation, then eliminate.
    5. Cauchy: f(x + y) = f(x) + f(y) gives f(x) = cx on ℚ. Over ℝ you need an extra condition (continuity, monotonicity, or bounded on an interval).
    6. Always verify the final answer in the original equation, and check that you didn't miss a family (like f ≡ 0).
    Common mistakes
    • Proving f(x) = x for some x and concluding it for all x (the "pointwise trap"). E.g. f(x)² = x² only gives f(x) = ±x for each x separately; the sign may switch.
    • Using continuity when the problem doesn't give it.
    • Forgetting to check the domain: f: ℤ → ℤ, f: ℝ+ → ℝ+ and f: ℝ → ℝ are different problems.
