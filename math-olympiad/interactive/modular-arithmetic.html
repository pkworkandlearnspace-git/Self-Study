See orders, primitive roots, and Fermat/Euler at work. The order of a mod n is the smallest d with ad ≡ 1. It's the single most useful idea in olympiad number theory (module 03).

Power table ak mod n

Rows: bases coprime to n. Blue cells: ak ≡ 1. A green row label = primitive root (order = φ(n)). Click a row to select that base.

Quadratic residues (p an odd prime)

a is a quadratic residue (QR) mod p if x² ≡ a has a solution. Squaring is 2-to-1 on the units (x and −x have the same square), so exactly (p−1)/2 units are QRs. The Legendre symbol (a/p) is +1 for a QR, −1 for a non-residue, 0 if p ∣ a. Euler's criterion computes it: (a/p) ≡ a(p−1)/2 (mod p).

arrow x → x² mod p (both x and p−x land on the same square) QR

Quadratic reciprocity at a glance

Cell (p, q) shows (p/q)·(q/p) for distinct odd primes. The law says it equals (−1)((p−1)/2)·((q−1)/2): it is −1 exactly when p ≡ q ≡ 3 (mod 4). The red cells sit exactly where the row prime and the column prime are both ≡ 3 (mod 4). Hover or tap a cell for the details.

 

Practice: use the laws (answers inside)
  1. Is 3 a QR mod 13? 13 ≡ 1 (mod 4), so (3/13) = (13/3) = (1/3) = +1. Indeed 4² = 16 ≡ 3.
  2. Is 5 a QR mod 23? 5 ≡ 1 (mod 4), so (5/23) = (23/5) = (3/5) = −1 (squares mod 5 are 1, 4). No.
  3. For which odd primes p is 2 a QR? (2/p) = (−1)(p²−1)/8: +1 iff p ≡ ±1 (mod 8). Check p = 7 (3² ≡ 2) and p = 5 (no).
  4. Show every prime divisor p of n² + 1 is 2 or ≡ 1 (mod 4). n² ≡ −1 (mod p) means (−1/p) = 1, i.e. (−1)(p−1)/2 = 1, so p ≡ 1 (mod 4).

Try these

  1. For prime n, does every order divide n − 1? (Fermat + order lemma.)
  2. For n = 13, count the elements of each order d. Compare with φ(d).
  3. Find an n with no primitive root (try 8, 12, 15). Primitive roots exist exactly for n = 1, 2, 4, pk, 2pk with p an odd prime (so 8 = 2³ has none).
  4. For prime p, is (p−1)! ≡ −1? Check Wilson's theorem in the panel. For composite n > 4, (n−1)! ≡ 0.
  5. In the QR panel, compare the QRs mod p with the even powers of a primitive root. Why are they the same set?
