Lattice Paths & Catalan

Each number is the count of right/up paths from the bottom-left corner to that point. It equals the sum of the counts to its left and below: Pascal's rule, i.e. a recursion. Add obstacles or a diagonal barrier and watch the counts change.

Try these

  1. In All paths, check that the corner count is C(m + n, m). Why? (Choose which m of the m + n steps go right.)
  2. In Never above y = x with m = n, read the corner values for n = 1…6: 1, 2, 5, 14, 42, 132. These are the Catalan numbers.
  3. Press Random bad path + reflection several times. The orange tail is reflected across y = x + 1 and always ends at (n − 1, n + 1). That bijection proves Cn = C(2n, n) − C(2n, n + 1).
  4. In Blocked points, click a point to block it. How many paths avoid the centre? Check by inclusion–exclusion: total − (paths through the centre).
