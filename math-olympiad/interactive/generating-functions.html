2 · Roots-of-unity filter

To count the subsets of an n-set whose size is ≡ r (mod m), i.e. Σk ≡ r C(n, k), average f(ωj)·ω−jr over the m-th roots of unity ωj, where f(x) = (1 + x)n. Every unwanted term cancels because 1 + ω + … + ωm−1 = 0.

ωj term f(ωj)·ω−jr (scaled) their sum (real!)
Row n of Pascal's triangle (purple = k ≡ r mod m)

Practice (solutions inside)

1. Find Σk C(n, 3k) in closed form.

With ω = e2πi/3: the sum is [2n + (1+ω)n + (1+ω²)n]/3. Since 1 + ω = eiπ/3 and 1 + ω² = e−iπ/3, the answer is (2n + 2cos(nπ/3))/3. Check n = 10 in Part 2: 2cos(10π/3) = −1, so (1024 − 1)/3 = 341.

2. How many subsets of {1, 2, …, 2000} have a sum divisible by 5? (A classic; IMO 1995 P6 is the same idea with p-element subsets.)

f(x) = ∏k=12000(1 + xk). For a primitive 5th root ζ, the exponents k run through each residue class mod 5 exactly 400 times, so f(ζ) = [(1+1)(1+ζ)(1+ζ²)(1+ζ³)(1+ζ⁴)]400. From x⁵ − 1 = ∏(x − ζj) at x = −1: ∏j=04(1 + ζj) = 2, so f(ζj) = 2400 for j = 1..4. Answer: (22000 + 4·2400)/5. Try the small version in Part 1 with (1+x)*(1+x^2)*…: the "Subsets of {1..10}" example, where the count of sum ≡ 0 mod 5 is (210 + 4·22)/5 = 208.

3. Prove: partitions of n into distinct parts = partitions into odd parts.

∏(1 + xk) = ∏(1 − x2k)/(1 − xk). Every even-exponent factor in the numerator cancels the matching denominator factor, leaving ∏k odd 1/(1 − xk). Load the Euler example: the two series coincide bar for bar.

4. Why do the Sicherman dice (1,2,2,3,3,4) and (1,3,4,5,6,8) give the same sum distribution as two ordinary dice?

x + … + x6 = x(1+x)(1+x+x²)(1−x+x²). Square it and regroup the factors differently: x(1+x)(1+x+x²) = x + 2x² + 2x³ + x⁴ and x(1+x+x²)(1−x+x²)² = x + x³ + x⁴ + x⁵ + x⁶ + x⁸. Both have value 6 at x = 1, so both are genuine dice.
