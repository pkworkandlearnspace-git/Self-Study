Longest Increasing Subsequence in O(n log n)

d[k] = the smallest tail of any increasing subsequence of length k+1. d is always sorted, so each new element either extends it or replaces the first entry ≥ it, which is one lower_bound per element (module 05, worked example 2).

Input array a
Tails array d (always sorted)
vector<int> d, pos, prv(n);          // pos[k] = index in a of the tail d[k]
for (int i = 0; i < n; i++) {
  int k = lower_bound(d.begin(), d.end(), a[i]) - d.begin();
  if (k == (int)d.size()) { d.push_back(a[i]); pos.push_back(i); }
  else { d[k] = a[i]; pos[k] = i; }
  prv[i] = k ? pos[k-1] : -1;          // predecessor, for reconstruction
}
// reconstruct: start at pos.back() and follow prv
