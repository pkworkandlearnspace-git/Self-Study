Prefix Function (KMP) Step-Through

π[i] = the length of the longest proper prefix of s[0..i] that is also its suffix (a border). To compute π[i], try to extend the previous border; on a mismatch, fall back to the next shorter border π[k−1] (module 06, worked example 2).

for (int i = 1; i < n; i++) {
  int k = pi[i-1];
  while (k > 0 && s[i] != s[k]) k = pi[k-1];   // fallback
  if (s[i] == s[k]) k++;
  pi[i] = k;
}
