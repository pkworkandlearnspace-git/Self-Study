LCA by Binary Lifting

up[j][v] is the 2j-th ancestor of v. Tap a node to set u and another to set v, then step through the two phases: (1) lift the deeper one to the same depth, (2) jump both while their ancestors differ (module 04).

uvLCAlast jump
Jump table row for the current u / v
if (dep[u] < dep[v]) swap(u, v);
for (j = LOG-1; j >= 0; j--) if (dep[u] - (1<<j) >= dep[v]) u = up[j][u];      // phase 1
if (u == v) return u;
for (j = LOG-1; j >= 0; j--) if (up[j][u] != up[j][v]) u = up[j][u], v = up[j][v];  // phase 2
return up[0][u];
