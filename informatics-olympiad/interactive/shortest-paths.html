What to notice

  • Dijkstra's invariant: when a node leaves the heap with the smallest tentative distance, no later path can beat it, because every other path must continue from a node that is already at least as far away and can only add non-negative weight. One negative edge breaks that "can only add" step. In the trap graph, node 1 is finalized at distance 2, and the cheaper route 0 → 2 → 1 (5 − 4 = 1) arrives too late.
  • This page uses the textbook version with a done[] array: a finalized node is never updated again. The common contest version without done[] (if (d != dist[u]) continue;) re-pushes improved nodes, so on graphs with negative edges but no negative cycle it still ends with the right answer, but it can take exponential time. Do not rely on it. Use Bellman–Ford or re-weight the graph (Johnson's trick).
  • Bellman–Ford: after round k, every shortest path that uses at most k edges is correct. A simple path has at most n − 1 edges, so n − 1 rounds are enough. If round n still relaxes an edge, there is a negative cycle reachable from the source. Every node reachable from that edge gets distance −∞.
  • 0-1 BFS: a 0-edge leads to a node at the same distance, so it goes to the front of the deque; a 1-edge goes to the back. The deque always holds at most two distinct distance values, d and d + 1, so it behaves like a sorted heap at O(1) per operation.
  • Make the "basic" graph undirected and add a negative weight: an undirected negative edge is itself a negative cycle (u → v → u). Negative weights only make sense on directed graphs.

Reference code

// Bellman–Ford with −∞ detection. INF = 4e18
vector<ll> d(n, INF); d[s] = 0;
for (int i = 0; i < n - 1; i++)
  for (auto [u, v, w] : edges)
    if (d[u] != INF && d[u] + w < d[v]) d[v] = d[u] + w;
// round n: anything that still relaxes is on or
// behind a negative cycle → propagate −∞
for (int i = 0; i < n; i++)
  for (auto [u, v, w] : edges)
    if (d[u] != INF && (d[u] == -INF || d[u] + w < d[v]))
      d[v] = -INF;
// 0-1 BFS
vector<int> d(n, INT_MAX); d[s] = 0;
deque<int> q{s};
while (!q.empty()) {
  int u = q.front(); q.pop_front();
  for (auto [v, w] : adj[u])
    if (d[u] + w < d[v]) {
      d[v] = d[u] + w;
      if (w == 0) q.push_front(v);
      else        q.push_back(v);
    }
}
