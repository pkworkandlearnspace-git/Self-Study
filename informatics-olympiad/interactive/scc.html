Condensation DAG

Shrink each SCC to one node. The result has no cycles, so you can run DP in topological order on it (longest path, reachability, 2-SAT assignment …). It fills in as components are found.

How it works

Tarjan (one pass)
  • tin[v] = DFS entry time. low[v] = smallest tin reachable from v's subtree using tree edges plus one edge to a node still on the stack.
  • Edges to nodes already assigned to a finished SCC are ignored: those nodes cannot reach back.
  • When low[v] == tin[v], v is the root of an SCC: pop the stack down to v.
  • SCCs come out in reverse topological order of the condensation (sinks first).
Kosaraju (two passes)
  • Pass 1: DFS on G, record nodes by exit time.
  • Pass 2: on the reversed graph, start DFS from nodes in decreasing exit time. Each DFS tree is one SCC.
  • The node that exits last lies in a source SCC of G, which is a sink in the reversed graph, so pass 2 cannot leak out of it.
  • SCCs come out in topological order (sources first).
// Tarjan, O(n + m). comp[v] = SCC id; ids are in reverse topological order.
int timer = 0, ncomp = 0; vector<int> tin(n, -1), low(n), comp(n, -1), st;
void dfs(int v) {
  tin[v] = low[v] = timer++; st.push_back(v);
  for (int to : adj[v]) {
    if (tin[to] == -1) { dfs(to); low[v] = min(low[v], low[to]); }
    else if (comp[to] == -1) low[v] = min(low[v], tin[to]);   // still on the stack
  }
  if (low[v] == tin[v]) {
    while (true) { int u = st.back(); st.pop_back(); comp[u] = ncomp; if (u == v) break; }
    ncomp++;
  }
}
// Recursion depth can reach n: for n = 2e5 on a path, raise the stack limit or write it iteratively.

2-SAT: for each clause (a ∨ b) add ¬a → b and ¬b → a. The formula is satisfiable iff no x is in the same SCC as ¬x. With Tarjan's ids (reverse topological), set x = true when comp[x] < comp[¬x]. Sources: cp-algorithms: SCC & condensation · cp-algorithms: 2-SAT · Wikipedia: Tarjan's algorithm.
