Fenwick Tree (BIT) Visualizer

Node i stores the sum of (i − lowbit(i), i], where lowbit(i) = i & −i. A prefix query removes the lowest bit at each step, and an update adds it. Both take O(log n) steps (module 03).

void add(int i, ll v) {      // 1-indexed
  for (; i <= n; i += i & -i) bit[i] += v;
}
ll sum(int i) {              // a[1] + … + a[i]
  ll s = 0;
  for (; i > 0; i -= i & -i) s += bit[i];
  return s;
}
