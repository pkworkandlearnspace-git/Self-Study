Convex Hull Builder

Andrew's monotone chain: sort the points, sweep left to right for the lower hull and right to left for the upper hull, and pop while the last turn is not a left turn. Every decision is one integer cross product, so there is no floating point (module 06). Click to add points, drag to move them.

// Andrew's monotone chain, O(n log n). Returns the hull counter-clockwise, no repeated first point.
// |coords| ≤ 1e9 → cross products reach about 8e18: still fits in long long (max ≈ 9.22e18).
using P = pair<ll, ll>;
ll cross(P O, P A, P B) { return (A.first-O.first)*(B.second-O.second) - (A.second-O.second)*(B.first-O.first); }
vector<P> hull(vector<P> p) {
  sort(p.begin(), p.end()); p.erase(unique(p.begin(), p.end()), p.end());
  int n = p.size(), k = 0; if (n < 3) return p;
  vector<P> h(2 * n);
  for (int i = 0; i < n; i++) {                      // lower hull
    while (k >= 2 && cross(h[k-2], h[k-1], p[i]) <= 0) k--;
    h[k++] = p[i];
  }
  for (int i = n - 2, t = k + 1; i >= 0; i--) {      // upper hull
    while (k >= t && cross(h[k-2], h[k-1], p[i]) <= 0) k--;
    h[k++] = p[i];
  }
  h.resize(k - 1); return h;
}
Traps
  • <= 0 drops collinear boundary points; < 0 keeps them. If you keep them and all points are on one line, the "hull" walks the line out and back, so every middle point appears twice. Handle that case separately.
  • Remove duplicate points first, or the pop condition sees a zero-length edge.
  • Twice the area (shoelace) is an integer. Keep it as an integer and only divide by 2 when you print.
  • Sort by x, then y. Sorting by x alone breaks ties on vertical edges in an arbitrary order.
