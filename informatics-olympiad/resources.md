# Informatics Olympiad Resources
⭐ = the main resource · 💲 = paid · everything else is free.

## The core stack
1. ⭐ **[USACO Guide](https://usaco.guide/)**: a structured curriculum from Bronze to Platinum, with problems per topic. Use it as the spine of modules 01–07.
2. ⭐ **[CSES Problem Set](https://cses.fi/problemset/)** (300+ classic problems) + **[Competitive Programmer's Handbook](https://cses.fi/book/book.pdf)** (free PDF, Laaksonen).
3. ⭐ **[AtCoder Educational DP Contest](https://atcoder.jp/contests/dp)**: for module 05.
4. ⭐ **Past IOI and olympiad tasks on [oj.uz](https://oj.uz/)**: subtask-judged practice.

## References
- **[cp-algorithms](https://cp-algorithms.com/)**: an encyclopedia of algorithms with proofs and code.
- **[KACTL](https://github.com/kth-competitive-programming/kactl)**: a well-tested code library (great for learning clean implementations).
- **Guide to Competitive Programming**, Laaksonen 💲 (the expanded handbook) · **Algorithms**, Erickson ([free](https://jeffe.cs.illinois.edu/teaching/algorithms/)) for proofs.
- **[cppreference](https://en.cppreference.com/)**.

## Practice & contests
- **[Codeforces](https://codeforces.com/)**: weekly contests, plus the **[EDU section](https://codeforces.com/edu/courses)** (segment tree, DSU, binary search courses).
- **[AtCoder](https://atcoder.jp/)**: ABC (beginner–intermediate), ARC/AGC (hard, math-flavored).
- **[IOI official site](https://ioinformatics.org/)**: the syllabus and past tasks.
- Past **APIO, BOI, CEOI, JOI, EGOI, and your national olympiad** problems (most are on oj.uz).
