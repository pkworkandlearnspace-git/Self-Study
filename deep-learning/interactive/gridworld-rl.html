Gridworld RL

One MDP, two ways to solve it. Value iteration knows the transition model and sweeps the Bellman optimality equation. Q-learning doesn't: it learns from sampled transitions with ε-greedy exploration. Edit the world, then compare.

Part of the Self-Study repo · deep-learning/interactive · Bellman optimality: V(s) = maxa Σs' P(s'|s,a)[r + γV(s')]. Q-learning: Q(s,a) ← Q(s,a) + α[r + γ maxa' Q(s',a') − Q(s,a)].
