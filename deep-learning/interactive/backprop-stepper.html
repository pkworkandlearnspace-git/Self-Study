Backprop Step-Through

Watch reverse-mode autodiff one node at a time, the way micrograd does it. The forward pass computes values left to right. The backward pass seeds L.grad = 1 and sends gradients right to left using only each node's local derivative: parent.grad += local × node.grad.

Updates every trainable leaf: θ ← θ − η · ∂L/∂θ. Inputs and targets stay fixed. Press it a few times and watch L fall.

Try this

  1. Neuron: before stepping backward, predict ∂L/∂w1 by hand. Hint: it is 2(h−y) · φ′(n) · x1. Then check.
  2. Neuron: by default x2 = 0. Why is ∂L/∂w2 exactly 0? (∂m2/∂w2 = x2: a weight on a zero input gets no gradient.) Set x2 = 1 and look again.
  3. Neuron with ReLU: make n negative (e.g. b = −10). Every upstream gradient becomes 0: a dead ReLU.
  4. Shared variable: a feeds two nodes, so its gradient is the sum of two paths. Forgetting the += is the classic micrograd bug.
  5. Deep chain with sigmoid: each layer multiplies the gradient by σ′ ≤ 0.25, so after 4 layers it is ≤ 0.004× smaller. Switch to tanh, then ReLU, and compare ∂L/∂x.
  6. Softmax + CE: confirm that ∂L/∂z1 = p1 − y1 and ∂L/∂z2 = p2 − y2, the famous ŷ − y.
