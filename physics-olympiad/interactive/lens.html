Thin Lens Ray Tracer

Drag the object (the arrow) or use the sliders. The three principal rays are traced through one or two thin lenses. A real image is drawn solid; a virtual one dashed, where the backward extensions of the rays meet. Predict where the image lands, then check (module 05).

Rules (Gaussian sign convention)

  • 1/f = 1/do + 1/di. Distances are positive for a real object (left of the lens) and a real image (right of the lens). f > 0 converging, f < 0 diverging.
  • Magnification m = −di/do. m < 0 means inverted. In a system, the magnifications multiply.
  • Two lenses: the image of lens 1 is the object of lens 2. If it lies beyond lens 2, it is a virtual object (do2 < 0).
  • Telescope (afocal, D = f₁ + f₂): angular magnification −f₁/f₂. Mirrors obey the same equation with f = R/2.
