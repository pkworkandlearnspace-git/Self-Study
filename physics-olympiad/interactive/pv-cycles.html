Formulas used (n = 1 mol, CV = R/(γ − 1))

  • Isothermal: ΔU = 0, Q = W = nRT ln(Vb/Va).
  • Adiabatic: Q = 0, pVγ and TVγ−1 constant, W = −ΔU = nCV(Ta − Tb).
  • Isochoric: W = 0, Q = ΔU = nCVΔT. Isobaric: W = pΔV, Q = nCpΔT.
  • Only the Carnot cycle reaches the Carnot limit, because all its heat is exchanged at Tmax and Tmin. A Stirling engine with a perfect regenerator (which stores the isochoric heat internally) also reaches it. Without one it falls short, as shown here.
